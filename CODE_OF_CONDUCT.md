# Code of Conduct

We want this project to be a respectful, welcoming place to collaborate.

- Be kind and assume good faith. Critique code and ideas, not people.
- No harassment, discrimination, personal attacks, or unwelcome sexual attention.
- Don't publish other people's private information.
- Maintainers may remove comments, issues or contributions that break these rules, and may block repeat offenders.

To report a problem, open a private security advisory on this repository or contact the maintainer through the email on their GitHub profile.

This is a short summary in the spirit of the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), which applies in full.
